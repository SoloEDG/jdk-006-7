# 雾港来电 · 午夜频率

## 安装

使用 Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8086 。可通过 PORT 环境变量修改端口。

## 同机分工模式

两名调查员轮流使用同一副耳机调查同一案件，全程本机运行、无需联网账号。

- 从单人模式顶部的「同机分工模式」进入，创建两名调查员。两人被分配到不同的可听场景，各自拥有独立的已听记录与私有手记，搭档的未公开录音标题、字幕搜索结果和笔记互不可见。
- 只有主动「提交」的声音线索与笔记才会进入**公共会议**，两人据此决定下一步。重复提交同一条证据只保留一份并列出全部贡献者；公开笔记保存提交时的副本，之后私下编辑不会回写会议。
- 「密封交接」会进入密封画面再轮到另一名调查员，画面只显示轮到谁与公开材料数量，不泄露任何私有内容。轮到谁、哪些已公开都会随存档准确保留。
- 分工存档（v2）与原有单人存档（v1）共用本地档案入口；旧的单人档案继续按原方式打开，互不影响。
